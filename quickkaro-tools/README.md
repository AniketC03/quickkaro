# QuickKaro Tools

Free static tools website for students, job seekers and creators.

## Deploy on Vercel

1. Create a Vercel account at https://vercel.com.
2. Click `Add New`.
3. Choose `Project`.
4. Import from GitHub, or upload this folder if your Vercel screen supports manual upload.
5. Framework preset: `Other`.
6. Build command: leave empty.
7. Output directory: `.`.
8. Click `Deploy`.

After deployment, replace `https://example.com` in `sitemap.xml`, `robots.txt`, and the schema inside `index.html` with your real Vercel or custom domain.

## Custom Domain

If you buy a domain, add it in Vercel project settings and then update DNS at your domain registrar.
